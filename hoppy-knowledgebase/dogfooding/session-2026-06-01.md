## New backlog items filed this round

- **MEDIUM** [[backlog/shield-metrics-waf-rule-flag-divergence]] —
  `shield metrics waf-rule` uses `--shield-zone-id` while every sibling
  uses `--id`. Inconsistent flag.
- **MEDIUM** [[backlog/statistics-chart-keys-unordered-json]] —
  `statistics` and `stream library statistics` return chart maps in
  HashMap (insertion) order. JSON output should be date-sorted so diffs
  and downstream consumers are deterministic.
- **MEDIUM** [[backlog/db-config-show-limits-ignore-format]] —
  `db config show` and `db config limits` always emit raw JSON,
  regardless of `--format`. Sister to [[backlog/db-active-usage-ignores-format]]
  but distinct.
- **MEDIUM** [[backlog/db-v2-list-table-placeholders]] —
  `db v2 list` table renders `<empty list>` / `<object: 3 fields>`
  placeholders for the envelope fields. The actual list of databases
  is never surfaced as a table.
- **LOW** [[backlog/dns-scan-results-domain-column-empty]] —
  `dns zone scan results --domain X` shows `Domain: -` in the table
  output, even though we just resolved the zone via that domain.
  Fill the column client-side.
- **MEDIUM** [[backlog/quiet-flag-no-op-on-many-commands]] —
  Global `--quiet` is documented as "Suppress non-essential output"
  but is a no-op on `auth check` (and likely other commands). Either
  honour it (suppress on success) or drop the flag.
