## Environment friction (not a hoppy bug)

The `cargo build --release` of `hoppy-cli` deadlocked in `pthread_cond_wait`
for >40 minutes across three attempts. Root cause: a second Claude Code
session was driving an autonomous iter-91 build on the sister repo
`/Users/james/devel/ff-rdp/`. Both held shared cargo registry resources
and the build script for `hoppy-cli` (`build.rs` shelling out to `git`)
hung at dyld load. `CARGO_HOPPY_FORCE_NO_GIT=1` did not help because the
hang was at process startup, not inside the script.

**Workaround for next session:** if a second Rust workspace under
`~/devel/` is being built by another agent, pause this build until that
one finishes. The cargo registry lock is global per OS user.
