# bunny-syslog-receiver

Embedded RFC 5424 / 3164 syslog TCP receiver with a pluggable tunnel abstraction. Used by `hoppy container logs` to receive Magic Containers log-forwarding streams. Part of the [hoppy](https://github.com/ractive/hoppy) workspace.

See the [hoppy repository](https://github.com/ractive/hoppy) for full documentation.
